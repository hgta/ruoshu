# 06 · 信息架构与关键页面设计

> 设计基线 · 2026-09-28
> 前置决策：女频 + 轻小说（轻小说独立成类）/ 打赏为主 + 章节付费 + 订阅 / 方案 B 技术栈 / 至信链存证

---

## 一、内容分类体系（已锁定）

采用 **"6 个一级导航 + 标签云自由组合"** 的混合方案。分类只承担"快速进入细分世界"的导航作用，
用户找书主要靠标签组合搜索 + 推荐。

```
一级导航（侧边栏 / 首页 Tab）：          二级标签（自由组合，无层级）：
├─ 古风言情  ─ 古言/穿越/重生/宅斗/宫斗   · 题材标签：穿越、重生、系统、无限流、群穿…
├─ 现言都市  ─ 职场/校园/婚恋/年代/行业  · 角色标签：女主强、男主病娇、白月光、女配逆袭…
├─ 玄幻仙侠  ─ 女主修真/玄幻言情/仙侠     · 情感标签：甜文、虐文、HE、BE、修罗场…
├─ 奇幻冒险  ─ 西方奇幻/异世界/轻奇幻     · 情节标签：爽文、慢热、剧情向、感情向…
├─ 科幻悬疑  ─ 末世/赛博/无限流/女主破案  · 风格标签：轻松、搞笑、治愈、暗黑、史诗…
└─ 轻小说    ─ ACG/系统/吐槽/校园（独立成类）· 时长标签：短篇、中篇、长篇、连载中、已完结…
                                          · 雷点标签：女主弱、绿帽、NTR（用于反向推荐/避雷）
```

决策理由：轻小说独立成类（不并入奇幻冒险）—— 二次元用户的阅读习惯
（吐槽文化、CP 党、画师联动）与女频差异明显，混类会让两边都不舒服。

## 二、站点地图

```
访客层（无需登录可访问大部分内容）：
├─ /                     首页（编辑精选 + 新书速递 + 完结榜 + 一级分类入口）
├─ /explore              分类浏览（一级分类 + 标签云 + 排序筛选）
├─ /books/{id}           作品详情页（封面/简介/目录/书评/打赏入口/存证徽章）
├─ /read/{chapter_id}    阅读页 ★核心场景（详见第四节）
├─ /authors/{id}         作者主页（作品列表/动态/粉丝/打赏排行）
├─ /search               搜索（关键词/标签/作者）
└─ /login /register      登录注册（主推微信扫码）

读者层（登录后）：
├─ /me                   我的主页（书架/历史/段评/打赏）
├─ /me/subscriptions     我的订阅（章节 + 月度会员）
├─ /me/notifications     消息中心（站内信/系统通知）
└─ /me/settings          账户设置

作者层（author 角色）：
├─ /author/dashboard     作者中心首页 ★（数据看板：阅读/打赏/订阅/盗用监测一屏）
├─ /author/books         作品管理（创建/编辑/列表）
├─ /author/books/{id}/chapters         章节管理（编辑器/版本/草稿/定时发布）
├─ /author/books/{id}/settings          作品设置（授权/定价/标签/封面）
├─ /author/earnings      收益管理（分账实时看板 + 提现 + 月对账单）
├─ /author/exports       数据导出（Markdown/EPUB/JSON/段评+UGC）
├─ /author/watermark     水印溯源 ★ 差异化功能（盗版监测列表 + 取证包下载）
└─ /author/legal         维权工具（一键生成律师函附件材料）

管理侧（独立子域 admin.* + IP 白名单 + 2FA）：
├─ /admin/users          用户管理
├─ /admin/books          作品审核（敏感词/AI 检测/原创检测报告）
├─ /admin/comments       评论审核
├─ /admin/reports        举报处理
├─ /admin/audit          操作审计（管理动作全程留痕，含签名）
└─ /admin/finance        财务审核（提现/分账对账）
```

设计原则：**作者侧是这款产品的真正主角**，入口不能藏太深，但不能挤占读者体验。

### UI 背后的技术含义

```
1. 段落渲染   每段独立 <p>，便于水印嵌入 + 段评锚点定位
2. 水印       每用户独立版本（W1 零宽 + W2 同义替换预计算查表渲染）
3. 段评       绑段落锚点，右侧浮层，可下拉刷新
4. 弹幕       Go WebSocket 推送（方案 B），漂浮右侧 5 秒淡出
5. 防截图     高价值书可启用 W4 渲染层字形指纹（详见研究文档 02）
6. 底部打赏   微信/支付宝 H5 支付 → 异步分账 → 流水进 ledger 批量上链
7. 阅读进度   前端定期上报（防丢失），同步书架"继续阅读"
```

## 五、首页信息密度策略

女频 + 轻小说用户的新书发现路径："刷信息流看到封面 → 看标签 → 看第一章"。

```
首屏（1.5 屏内）：
  · 编辑精选横幅（3 本，配插画级封面）
  · 新书速递（本周新书 8 封面横滑）
  · 完结榜 / 人气榜（两个 Tab，各 10 本带封面卡片）
二级屏：
  · 分类入口宫格（6 个一级分类，各配插画）
  · 标签热度云（可点击组合搜索）
三级屏：
  · 打赏动态流（"小兔子 刚刚投喂了 枕书听雨 的《长夜未央》"—— 制造氛围）
  · 段评精选（把最有梗的段评做成内容卡，直接引流到章节锚点）
```

"段评精选"是首页的差异化模块：**把 UGC 当内容运营**，段评本身有传播性（截图出圈）。

## 六、阅读页适配与阅读体验细节

- 三套主题：白 / 米黄（仿纸）/ 夜间；字号行距可调
- 移动端优先（女频用户 80%+ 是移动端），阅读页按 375px 设计基准
- 优雅降级：WebSocket 不可用时段评/弹幕自动切 5s 轮询
- 会员权益提示不打断阅读：解锁提示只出现在章末，不在正文中插广告位
  （与免费阅读平台的核心区别：**本平台靠打赏/付费/订阅变现，不靠广告**）
