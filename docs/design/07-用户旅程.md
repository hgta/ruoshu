# 07 · 用户旅程设计

> 设计基线 · 2026-09-28
> 三类关键旅程：读者（发现→打赏）、作者（想法→第一笔收益→维权）、管理员（审核→DMCA 响应）

---

## 旅程 A：读者 —— 从发现到打赏

```
[Twitter/小红书/B站 引流]        [站内信息流/搜索]
     │                              │
     └──────────┬───────────────────┘
                ▼
        /books/{id} 作品详情页
          · 看简介、标签、段评热度
          · 注意到"已上链存证"徽章（信任建立）
                │
                ▼
        /read/{chapter_id} 开始阅读
          · 前 3 章免登录
                │
                ▼
        第 4 章为 VIP ──→ 弹登录
                │
                ▼
        /login 微信扫码注册（10 秒内完成）
          · 自动设默认昵称/头像，事后可改 → 不打断心流
                │
                ▼
        继续阅读（VIP 解锁流程）
          · 单章解锁 0.2 元 / 月卡已涵盖 → 微信支付
                │
                ▼
        在某段精彩处点击发段评
          · 看到其他读者的段评/弹幕（氛围感）
          · 段评发送 → WebSocket 即时上屏
                │
                ▼
        [打赏按钮] → 礼物选择器 → 微信支付 ¥1
                │
                ▼
        分账：作者实时到账 0.85 元（平台抽 15%）
                │
                ▼
        弹幕区飘过"感谢 小兔子 投喂的小星星 ⭐"
          · 作者侧 dashboard 同时收到推送
                │
                ▼
        [次日] /me 书架提醒"你追的 3 本书更新了"
          · 消息中心聚合更新通知（RSS 同步生成）
```

**体验红线**（不可妥协）：
1. 注册到回到阅读 ≤ 15 秒（扫码 + 自动昵称）
2. 支付成功到弹幕上屏 ≤ 3 秒（分账结果异步，反馈先行）
3. 段评发送即上屏（乐观 UI + WebSocket 广播）

## 旅程 B：作者 —— 从想法到第一笔收益到维权

```
注册 → 选笔名 → 开通作者身份（实名认证，为存证主体资格）
    │
    ▼
进入作者中心，首页引导卡：
    ① 选授权协议（默认推荐 CC BY-NC-ND，协议徽章说明）
    ② 创建第一部作品
    │
    ▼
创建作品
    · 上传封面、选一级分类 + 标签（≥3 个）
    · 选授权协议 → 哈希上链记录
    │
    ▼
章节编辑器
    · 富文本，每 10 秒自动保存草稿（防丢稿焦虑）
    · 字数统计、敏感词提示（发布前预检）
    │
    ▼
点击发布 ──→ 触发三件异步事：
    ① 至信链存证（约 30 秒返回存证号）→ 作品页挂徽章
    ② 水印方案预生成（同义替换锚点匹配）
    ③ RSS 推送订阅者 / 站内更新通知
    │
    ▼
作品页展示"已上链存证 · 存证号 xxx · 点击验证"
    · 验证页：粘贴任意一段原文 → 现场算 SHA-256 → 匹配链上记录
    · 作者信任感闭环
    │
    ▼
[时间流逝… 一周内收到第一笔打赏]
    │
    ▼
作者中心 → dashboard 推送
    · ¥0.85 已到账 · 读者昵称 · 来源章节
    · 打赏弹幕回礼功能（作者可回复感谢，读者收到通知）
    │
    ▼
[一个月后] dashboard 数据看板
    · 阅读量 / 打赏数 / 订阅数 / 段评热度 / 盗用监测（全在一屏）
    │
    ▼
[某天发现盗版] → 作者中心 → /author/watermark
    · 粘贴盗版文本或提交盗版链接
    · 系统跑段落指纹比对 + 水印提取
    │
    ▼
溯源结果：3 个嫌疑账号 · 置信度 78%
    · 展示比对详情（哪些段落命中、锚点 bit 序列）
    │
    ▼
下载取证包 PDF（链上证书 + TSA 证书 + 哈希清单 + 比对报告）
    · /author/legal 提供律师函模板 + 材料清单
    · 平台内处置：对泄露账号一键封禁（作者自主决定）
```

**体验红线**：
1. 从"写完"到"发布成功"无感存证（异步，不阻塞）
2. 打赏到账通知 ≤ 5 秒
3. 溯源全流程（提交→结果）≤ 10 分钟（异步任务 + 通知）

## 旅程 C：管理员 —— 内容审核与 DMCA 响应

```
admin 子域（独立子域 + IP 白名单 + 2FA）
    │
    ▼
仪表盘：今日待处理
    · 评论举报 12 · 章节 AI 检测告警 3 · DMCA 请求 1
    │
    ▼
逐项处理：
    ├─ 评论举报 → 人工 review → 置顶/隐藏/封号 → 留痕 + 签名
    ├─ AI 检测告警 → 查看置信度 → 人工抽检 → 标记/退回作者
    └─ DMCA 请求 → 加载作者提供的取证包
         → 验证链上证书有效性（至信链查验接口）
         → 站内下架侵权作品 / 转法务跟进
    │
    ▼
所有管理操作写入 audit_logs
    · 不可删除，含操作人签名
    · 定期打包 Merkle root 上链（管理动作也可追溯）
```

**运营前置**：审核 SOP、敏感词库、AI 检测阈值（Block/Review/Pass 三级）在 M1 上线前必须就绪，
不能"先上线后补审核" —— 存证平台的内容合规责任更重。

## 四、旅程中的"上链时刻"全景（产品叙事线）

| 触发点 | 动作 | 用户感知 |
|--------|------|---------|
| 选择授权协议 | 协议文本哈希上链 | "我的授权选择被永久记录" |
| 发布章节 | Merkle root 上链（付费章逐章） | 作品页存证徽章 |
| 打赏/付费 | 流水进 ledger，每小时批次上链 | 作者端"链上校验"按钮 |
| 月度结算 | 月对账单 root + TSA 时间戳 | 月对账 PDF 附证书 |
| 发现盗版 | 取证包生成（链证书 + TSA 取证） | 可直接给律师 |
| 管理动作 | audit 批次上链 | 平台行为也可追溯 |

**产品哲学**：让"上链"不是后台的黑箱，而是作者随时可感知、可验证的**信任仪式**。
