## 核心结论速览（Executive Summary）

### 1. 产品定位
「主打原创、保护作者版权」是一个真实的市场空白：国内平台抽成 30-50% 且普遍要求买断/独家授权，
海外平台（Substack/Patreon/Ko-fi）抽成 0-12% 且版权完全归作者。**"作者主权 + 技术性版权保护"
的组合叙事在国内尚无对标产品。**

### 2. 技术选型建议（详见文档 01）
- **推荐主架构**：Laravel (PHP) 主站单体 + Go 实时服务（段评/弹幕/推送）+ Python AI 边车（水印/AIGC 检测）
- 若坚持纯 PHP：Hyperf（Swoole 协程）可一站式覆盖传统页面 + 长连接，是 PHP 阵营的现代答案
- 存储：MySQL 8（内容表垂直拆分）+ Redis 热章缓存 + Meilisearch 全文检索（中小规模够用，ES 备选）
- 云上部署：腾讯云/阿里云，双机起步（应用 + 数据），CDN + OSS 必配

### 3. 版权保护技术分层（详见文档 02/04）
```
第 1 层  技术性防盗版      字体混淆 / 章节错位 / Canvas 渲染        —— 防"爬"
第 2 层  内容级盲水印      零宽字符 + 同义词替换 + 段落指纹          —— 防"偷"且能溯源
第 3 层  法律性确权        至信链(1元/条) / TSA 可信时间戳           —— 能"告"
第 4 层  监测与取证        哈希比对 + 链上证书 + 电子取证            —— 能"赢"
```

### 4. 上链结论（详见文档 04）
**不建议直接自建联盟链**。推荐双轨制：
- 章节确权 → **腾讯至信链 API**（1 元/条，接入最快，司法合作成熟，深圳前海法院对接）
- 关键证据/付费内容 → 补 **TSA 可信时间戳**（杭州互联网法院判例多，AIGC 存证有专项）
- 只上 SHA-256 哈希 + 元数据，**原文永不上链**（合规 + 成本）
- 分级策略：免费书本地哈希 + 打包上链，付费书/签约书全量逐章上链

### 5. 作者主权落地（详见文档 03）
- 一键导出：Markdown / EPUB / TXT / JSON（含读者段评等 UGC 附属数据）
- 授权协议选择器：默认 CC BY-NC-ND，作者可自选，平台永不买断
- 透明分账：实时结算看板 + 分账流水哈希上链（对账不可篡改）
- 联邦分发：作品 RSS 输出 + ActivityPub 出口（后期），降低平台绑架感

### 锁定决策对产品的影响

**女频 + 轻小说带来的设计含义**：
- 段评/弹幕是核心氛围 → Go 实时服务优先级 M1 即需
- 画师/二创生态强 → 需要图片管线（封面、角色卡、CP 图、画廊）
- 完结率高 + 订阅意愿强 → 订阅制可作为稳定营收，配合章节付费 + 打赏的三层组合
- 用户偏年轻 → UI 可更活泼，互动元素（角色弹幕、CP 投票）权重提高
- 情感共鸣场景多 → 段评不应只绑句子，可绑定角色（"在 XXX 角色出镜时发评论"）

**打赏为主商业模式的设计含义**：
- 分账引擎"逐笔实时可见"是核心 UX（每笔打赏的分成即时到账动画）
- 打赏场景需要"礼物系统"（不只是金额数字）—— 女频读者很吃仪式感
- 章节付费 + 订阅是补充：章节定价宜偏低（0.1-0.5 元），订阅宜按月卡（会员制）
- 高频小额支付的合规成本要预留：微信/支付宝分账接口是必需

**"不做独家"的替代钩子**（决策 #6 详述）：
- 创作者基金：月度评选 TOP 50，奖金池非排他
- IP 撮合：影视/出版/动画对接，作者自主选择，平台抽 10% 撮合费
- 透明分账：抽成透明到每一分钱（ledger 链式哈希 + 批次上链）
- 版权保护：上链存证 + 水印溯源 + 取证包 —— 独家签约给不了的真护城河
- 叙事一致性：平台口号是"作品归作者"，独家 = 叙事裂缝，坚决不做

**首发规模基线（决策 #7）**：
- 起步期（M1-M3）：500 部作品（30% 完结搬运 + 70% 新作）/ 日更 80-150 章 / DAU 1000-3000
- 付费章节占比 20-30%，月上链 ~2000 条（约 2000 元/月）
- 服务器 2C4G×2 + 云数据库 + CDN/OSS/短信 ≈ 3000-5000 元/月
- **总月运营成本 6000-8000 元**（可覆盖至 5000 DAU）
