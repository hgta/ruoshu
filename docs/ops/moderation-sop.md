# 内容审核 SOP（任务 13.1）

> 开放注册（`features.registration = true`）的前置条件：本 SOP 落地 + 敏感词库导入完成。

## 1. 时效承诺

| 队列 | 首响 | 处结 |
|---|---|---|
| DMCA / 权利主张 | 2 小时内 | 72 小时内出处置结论 |
| 涉黄涉暴举报 | 1 小时内 | 24 小时内 |
| 普通举报（垃圾/广告） | 4 小时内 | 72 小时内 |

## 2. 处置原则（红线）

1. **先证据后处置**：任何下架/隐藏动作必须能引用证据（存证记录、取证包、敏感词命中、原样截图）。DMCA 必须先过证据面板（任务 12.3）。
2. **强制备注**：admin 后台所有处理动作必须 ≥5 字备注（表级非空 + 前端校验）。无备注的处置一律退回。
3. **存证不可破坏**：下架不影响 `evidence_records`；账本 `ledger_entries` append-only；audit_logs 带操作人签名（篡改必校验失败）。
4. **低置信不自动封禁**：水印溯源置信度 < 0.9 只出人工比对报告，不指向具体账号。

## 3. 敏感词库维护

- 词库来源：开放词库（如开源政治敏感词/暴恐词表）+ 商用词库服务。
- 维护入口：admin 后台（规划中 Filament → 现自建后台），更新后重建 DFA 缓存。
- 命中处理：发布侧拦截（弹幕/评论 422）；审核队列可见命中记录。

## 4. 升级路径

- 争议处置 → 转法务（后台动作 `legal`：内容下线 + 证据随工单移交）。
- 涉刑线索 → 按《网络安全法》第 47 条向主管部门报告，平台侧留存全部日志。
